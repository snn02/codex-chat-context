# Панель контекста · 0.3.2

Локальная панель для текущего чата Codex, оформленная по образцу Claude. Идентификатор плагина сохранён: `context-panel-probe@context-panel-probe-local`.

## Использование

Откройте инструмент «Контекст чата» (`open_panel`) в нужном чате. Данные обновляются каждые пять секунд, пока панель видна. Кнопка «Обновить» запрашивает свежие данные сразу.

Версия 0.3.0 установлена штатной командой `codex plugin add` поверх прежнего плагина. Списки поддерживают открытие файлов по клику. Если открытая вкладка показывает прежний интерфейс, закройте её и откройте панель заново.

## Данные и точность

- Общий объём: `last_token_usage.total_tokens`, при его отсутствии сумма входа и выхода. Накопленный `total_token_usage` не используется. После счётчика добавляется оценка новых записей.
- Лимит: `model_context_window` из локального журнала. Если его нет, процент и свободное место недоступны.
- Сообщения и результаты инструментов: приближённая оценка текстового объёма. Изображения, точные схемы и внутреннее представление модели полностью восстановить нельзя.
- Навыки: размер доступного каталога, а не всех файлов SKILL.md. Файлы инструкций берутся только из явного снимка `world_state.state.agents_md`. Упоминания путей в сообщениях, коде и результатах инструментов не добавляют файлы в список. Пустой список означает отсутствие подтверждённых записей в этом источнике, а не отсутствие любых инструкций у модели.
- MCP и встроенные инструменты: наблюдавшиеся вызовы и доступный отложенный каталог пространств имён. Это не полный список схем. Неизвестные размеры отмечены прочерком.
- Прочий системный контекст: остаток между измерением и известными частями. Он не равен точному размеру системного промпта. При превышении измерения части пропорционально нормируются.
- После сжатия история помечается неполной; старые оценки сообщений сбрасываются. Это намеренно консервативная разбивка.

Свободное место — подтверждённый лимит минус занятый объём. Отложенные каталоги показаны отдельно и повторно не добавляются к полосе.

## Привязка и локальность

Сервер принимает ID только из доверенных метаданных вызова MCP. UI не передаёт ID чата; конфликтующие ID отклоняются. Перед публикацией агрегатов проверяется `session_meta.id` в найденном JSONL. Для каждого чата отдельный кеш. Частичные строки, порционное чтение, усечение и изменение файла обрабатываются отдельно.

Источник — `%CODEX_HOME%/sessions` либо `%USERPROFILE%/.codex/sessions`. Панель не вызывает модель и не обращается во внешнюю сеть. DTO содержит агрегаты, имена инструментов, пути и статус источников; тексты сообщений, инструкций и рассуждений в него не передаются. Путь проекта и ID доступны в раскрываемой диагностике.

## Проверка

В каталоге плагина:

```powershell
node --test tests/*.test.cjs
node --check server.cjs
node --check panel.js
```

Результат на 19.10.2026: 30/30 теста проходят. Независимое ревью выявило четыре важных дефекта; для всех добавлены сначала падающие регрессионные тесты и исправления.

Браузерная проверка на настоящих агрегатах двух чатов: ширины 360/540 px, раскрытие MCP, переход A → B → A. Скрытие остановило счётчик запросов на 20, показ возобновил обновление. Мост Codex в этом предпросмотре имитируется. Снимок: `docs/context-panel-preview.jpg` в корне проекта.

Локальный проверочный сервер (не нужен для работы установленного плагина):

```powershell
node scripts/preview.cjs <thread-uuid> [second-thread-uuid]
```

Он слушает только `127.0.0.1`, выдаёт случайный адрес и показывает только агрегаты переданных чатов. Остановить: Ctrl+C.

## Открытие по клику

Каждый элемент списков — кнопка. Навыки и файлы инструкций открывают существующий Markdown-файл отдельной вкладкой Codex через `openai/files/open`. Короткие пути навыков r0/r1 и т. п. раскрываются по таблице корней из того же журнала. Исходные файлы не изменяются.

Для MCP и встроенных инструментов сервер создаёт локальную текстовую карточку во временной папке `codex-context-files-*`. Она содержит доступное описание каталога и имя инструмента. Это не исходный код; полная схема параметров в текущем источнике отсутствует. Аргументы/результаты вызовов в карточку не включаются.

Новая команда `prepare_context_file` доступна только UI. Она принимает группу и ключ выбранной записи, проверяет привязку чата и ищет запись в его текущем каталоге; произвольный путь не принимается. Если файл отсутствует или хост не поддерживает открытие вкладок, панель сообщает причину. После установки новой команды уже запущенному серверу может потребоваться перезапуск Codex.

Проверка 0.3.0 (20.10.2026): 30/30 тестов; браузерный клик по imagegen/SKILL.md возвращает его настоящий путь, клик по MCP создаёт карточку и вызывает команду открытия. В предпросмотре открытие вкладки имитируется. Старая вкладка внутри Codex и запущенный MCP-процесс ещё не подхватили 0.3.0; окончательная проверка клика в нативном хосте ожидает перезапуска.
